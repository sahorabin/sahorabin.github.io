기록은 촬영에 집중하고,

Pushup Video Pipeline은 개인 운동 기록 영상을 사용자가 지정한 Apple Photos 앨범에서 가져와 정해진 세로형 레이아웃으로 편집하고, 연결된 본인 계정의 YouTube Shorts와 Instagram Reels에 게시하는 개인용 macOS 자동화 도구입니다.

How it works

영상이 게시되는 과정

01 / SELECT

영상 선택

사용자가 Apple Photos에서 게시할 영상을 선택하고 지정된 앨범에 추가합니다. 앱이 모든 사진을 임의로 게시하는 것은 아닙니다.

02 / COMPOSE

영상 구성

원본의 사용자 편집 구간을 보존하며 참조 영상, 날짜별 챌린지 표기, 촬영 영상을 하나의 세로 영상으로 구성합니다.

03 / PUBLISH

계정에 게시

사용자가 사전에 승인하고 연결한 YouTube 채널과 Instagram 계정으로 게시합니다. 게시 기록을 사용해 중복 게시를 방지합니다.

Data & permissions

Google 계정 권한은 왜 필요한가요?

이 앱은 YouTube에 동영상을 업로드하고 연결한 채널을 확인하기 위해 Google OAuth 인증과 YouTube API 서비스를 사용합니다. Google 계정의 비밀번호를 앱에 직접 입력하지 않으며, 승인된 인증 정보를 통해 필요한 작업을 수행합니다.

이 웹사이트는 소프트웨어를 판매하거나 누구나 가입하도록 제공되는 서비스가 아닙니다. 실제 동영상 처리 및 게시 프로그램은 소유자의 Mac에서 실행됩니다. 이 공개 페이지는 앱의 목적과 데이터 처리 방식을 설명하기 위한 안내 페이지입니다.

YouTube 게시 시 공개 범위는 앱에 설정된 값(현재 기본값: 미등록)에 따르며, Instagram 게시물의 공개 범위는 해당 계정과 플랫폼 설정을 따릅니다. 이 웹사이트에서는 로그인이나 영상 업로드를 받지 않습니다.

This is a personal macOS utility. It processes user-selected exercise videos locally and uses Google OAuth / YouTube API Services and the Instagram API to publish to accounts authorized by the operator. This website does not provide account sign-up or accept media uploads.
