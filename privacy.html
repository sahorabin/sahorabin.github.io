개인정보처리방침

최종 수정: 2026년 11월 18일 · 운영 주체: Pushup Video Pipeline 개인 개발·운영자

Pushup Video Pipeline(이하 “앱”)은 개인 운동 영상의 로컬 편집 및 소유자가 승인한 계정으로의 자동 게시를 지원하는 macOS 도구입니다. 앱은 Google OAuth 및 YouTube API 서비스를 사용합니다. 아래는 앱의 데이터 처리 목적과 범위에 대한 안내입니다.

1. 처리하는 정보

  • 선택한 동영상: 사용자가 지정한 Apple Photos 앨범의 영상 및 영상 메타데이터(촬영 시각, 편집 구간, 파일 식별 정보 등).
  • 연결된 계정 정보: YouTube 채널 식별자, 계정에 부여된 OAuth 권한 및 Instagram 게시 계정의 식별 정보.
  • 게시 기록: 작업 상태, 업로드 대상, 영상 식별자, 게시 URL, 처리 시각, 중복 방지용 해시 및 오류·진단 로그.
  • 인증 정보: Google OAuth 토큰 등 계정 접근에 필요한 인증 정보. 개인 Mac의 보안 저장소(예: macOS Keychain)를 사용할 수 있습니다.

2. 처리 목적

영상 수집·편집·게시, 연결 계정 확인, 예약 작업 실행, 게시 결과 검증, 중복 게시 방지, 장애 진단과 안전한 복구를 위해서만 위 정보를 사용합니다. 요청한 게시 작업과 무관한 광고 타기팅이나 데이터 판매를 목적으로 사용하지 않습니다.

3. Google 사용자 데이터 및 YouTube API

앱은 Google OAuth를 통해 YouTube 업로드와 채널 확인에 필요한 범위의 권한을 요청합니다. Google 비밀번호를 직접 수집하지 않습니다. 사용자는 Google 계정의 제3자 앱 연결 관리에서 액세스를 철회할 수 있습니다.

이 앱은 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받는 YouTube API 서비스를 사용합니다. YouTube에 업로드된 콘텐츠와 플랫폼 측 데이터는 YouTube의 정책 및 해당 계정 설정에 따라 별도로 관리됩니다.

4. 저장 장소 및 제3자 제공

선택된 영상의 작업용 사본, 게시 이력 및 진단 로그는 주로 앱 운영자의 Mac에 저장됩니다. 게시 명령을 실행하면 동영상과 게시 메타데이터가 승인된 YouTube/Google 및 Instagram/Meta 서비스로 전송됩니다. 이 웹사이트 자체는 계정 로그인, 영상 접수 또는 방문자 추적용 분석 스크립트를 제공하지 않습니다. 웹 호스팅 제공자는 사이트 접속 과정에서 기본적인 기술 로그를 처리할 수 있습니다.

5. 보관, 삭제 및 접근 철회

로컬 영상 사본과 게시 이력은 작업 검증·중복 게시 방지·문제 해결에 필요한 동안 보관하고 운영자가 관리합니다. 데이터 삭제 또는 처리 관련 문의는 아래 연락처로 요청할 수 있습니다. 요청을 받으면 해당 데이터의 성격과 적용되는 플랫폼 규정을 확인하여 처리합니다.

중요: 앱의 로컬 데이터를 삭제하거나 OAuth 연결을 철회해도 이미 YouTube 또는 Instagram에 게시된 영상이 자동 삭제되는 것은 아닙니다. 해당 플랫폼의 콘텐츠 삭제는 각 플랫폼에서 별도로 수행해야 합니다.

6. 보안

앱은 계정 접근 정보를 공개 웹사이트에 게시하지 않고, 로컬 운영 환경에서 관리합니다. 인증 정보 및 로그에 대한 접근은 운영자에게 제한합니다. 외부 서비스와 통신할 때에는 해당 플랫폼이 제공하는 보안 연결을 사용합니다.

7. 연락 및 정책 변경

문의 또는 데이터 삭제 요청: sahora.bin@gmail.com. 본 방침은 앱의 실제 처리 방식이 변경되는 경우 갱신되며, 변경된 날짜를 이 페이지에 표시합니다.

English summary

Privacy summary (English)

Pushup Video Pipeline is a personal macOS application that prepares user-selected exercise videos and publishes them to accounts authorized by the operator. It uses Google OAuth and YouTube API Services for YouTube upload and channel checks, and the Instagram API for Instagram publishing. It may process video files and metadata, channel identifiers, authentication credentials, upload receipts and diagnostic logs for publishing, safety and duplicate prevention.

Working media and operational records are primarily stored on the operator’s Mac; publishing transfers selected content to Google/YouTube and Meta/Instagram. The website itself has no sign-up or media upload feature and uses no analytics script. To revoke Google access, visit Google Account permissions. For requests concerning locally stored data, contact sahora.bin@gmail.com. Removing local data does not delete content already published on YouTube or Instagram. The app uses YouTube API Services subject to the YouTube Terms of Service and Google Privacy Policy.
