1. 도구의 목적

Pushup Video Pipeline은 운영자 본인의 운동 기록 영상을 로컬에서 편집하고, 사용자가 승인한 YouTube 및 Instagram 계정에 예약 게시하는 개인용 macOS 도구입니다. 공개 회원가입이나 제3자를 위한 영상 호스팅 서비스를 제공하지 않습니다.

2. 승인된 계정 및 콘텐츠

운영자는 직접 접근 권한이 있는 계정에 대해서만 앱을 사용해야 합니다. 게시하는 동영상, 음악, 이미지 및 인물의 초상에 필요한 권리와 동의를 확보할 책임은 게시자에게 있습니다. 앱은 사용자의 명시적 설정과 게시 승인 범위를 벗어난 콘텐츠를 의도적으로 게시해서는 안 됩니다.

3. 외부 플랫폼

YouTube 및 Instagram 게시에는 각 서비스의 이용 조건, 공개 범위 설정, API 제한과 정책이 적용됩니다. YouTube API 서비스를 이용한 기능에는 YouTube 서비스 약관 및 YouTube API 서비스 이용약관이 적용됩니다.

4. 가용성 및 결과 확인

예약 실행·네트워크·인증 또는 외부 플랫폼 사정으로 게시가 지연되거나 실패할 수 있습니다. 앱은 실행 기록과 플랫폼 응답을 통해 결과 확인 및 중복 게시 방지를 시도하지만 모든 게시의 즉시 성공을 보장하지 않습니다. 실제 게시 및 공개 범위는 해당 플랫폼의 계정 화면과 기록을 통해 확인해야 합니다.
